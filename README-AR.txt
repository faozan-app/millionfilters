GOLD GLOBE — حزمة تحديث القلادة الفاخرة

تحتوي الحزمة على:
1) index.html — صفحة الموقع كاملة بعد إضافة القلادة.
2) gold-globe-necklace.webp — صورة القلادة الفاخرة.

طريقة التثبيت في GitHub:
- افتح المستودع الذي ينشر millionfilters.com.
- ارفع الملفين إلى جذر المستودع، في نفس مكان index.html الحالي.
- استبدل index.html القديم، وارفع صورة القلادة الجديدة.
- احتفظ بالملفات الأصلية التالية دون حذف أو إعادة تسمية:
  gold-bar-clean.webp
  mountains-soft.webp
  earth-spin.mp4
- لا تحذف الملفات القديمة الأخرى. هذه الحزمة تحديث فوق الموقع الحالي، وليست نسخة منفصلة مكتملة بدون الأصول السابقة.
- افتح https://millionfilters.com/ واختبر الأسعار والأوزان والفيديو وصورة القلادة والمشاركة.

ملاحظات:
- سعر الذهب يأتي من API سابقًا وقد يتعذر عرضه إن تعطلت الخدمة أو الاتصال.
- صورة معاينة واتساب (Open Graph) تشير إلى gold-globe-necklace.webp؛ قد تحتاج المعاينة إلى وقت حتى يتحدث تخزين واتساب المؤقت.
- رقم الواتساب نص عادي وليس رابطًا، كما تم تعطيل الاكتشاف التلقائي للهواتف عبر meta format-detection في المتصفحات التي تدعمه.
- التصميم المعروض للقلادة تصور فني بصري، وليس منتجًا معروضًا للبيع.
