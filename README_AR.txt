GOLD GLOBE - تحديث الزرين

1. فك ضغط الحزمة.
2. ارفع ملف index.html فقط إلى جذر مستودع millionfilters في GitHub مع الاستبدال.
3. لا تحذف ملفات الصور الحالية أو virtual.html.
4. اختبر https://millionfilters.com/ ثم اضغط الزر الأخضر للانتقال إلى https://millionfilters.com/virtual.html

التعديل: زر مشاركة الذهب يتغير حسب لغة الجهاز، وزر شراء الذهب الافتراضي الأخضر أسفله مترجم أيضًا. باقي وظائف الموقع محفوظة، ومنها Google Analytics 4.

ملاحظة: ربط رسائل SMS في virtual.html يحتاج إعداد خدمة مصادقة منفصلة.
